# Public API Contract: SpectrumUIFoundations (v0.2.0)

**Feature**: 002-foundations-tokens
**Date**: 2026-05-09

This document is the binding contract for the public surface of `SpectrumUIFoundations`
in v0.2.0. Anything described here is the consumer-facing API; everything else is
internal and may change without notice.

## 1. Module Entry & Removed Symbols

```swift
// Removed in v0.2.0 (was in v0.1.0):
public enum SpectrumUIFoundations { public static let moduleName = "SpectrumUIFoundations" }
```

The empty namespace and `moduleName` constant from v0.1.0 are **removed**. Pre-1.0.0
versioning permits this break (per Constitution Governance).

## 2. Top-Level Namespace

```swift
public enum Spectrum {
    public static var color: ColorTokens { … }
    public static var spacing: SpacingTokens { … }
    public static var typography: TypographyTokens { … }
    public static var motion: MotionTokens { … }
    public static var elevation: ElevationTokens { … }
    public static var radius: RadiusTokens { … }
    public static var opacity: OpacityTokens { … }
    public static var sizing: SizingTokens { … }
}
```

`Spectrum` is the single entry point. All eight categories are reachable via dot-paths.

## 3. Token Categories (Generated)

Each category is its own typed namespace generated by the SPM command plugin. The exact
identifiers come from the Spectrum JSON snapshot. Examples (illustrative, not exhaustive):

```swift
// Color — SpectrumColor values; ShapeStyle conforming
Spectrum.color.accent.s500             // SpectrumColor
Spectrum.color.background.primary      // SpectrumColor
Spectrum.color.text.body               // SpectrumColor

// Spacing / Sizing / Radius — CGFloat
Spectrum.spacing.s100                   // CGFloat (4 pt)
Spectrum.spacing.s200                   // CGFloat (8 pt)
Spectrum.sizing.s400                    // CGFloat (32 pt)
Spectrum.radius.s200                    // CGFloat (8 pt)

// Typography — SpectrumFont
Spectrum.typography.bodyM
Spectrum.typography.headingL

// Motion — SpectrumDuration
Spectrum.motion.transitionMedium

// Elevation — SpectrumElevation
Spectrum.elevation.layer2

// Opacity — Double
Spectrum.opacity.disabled               // 0.4
```

**Stability**: The category list is stable across v0.2.x. Adding a new category is a
MINOR bump; renaming or removing a category is MAJOR.

## 4. Value Types

```swift
public struct SpectrumColor: ShapeStyle, Equatable, Sendable { … }

public struct SpectrumFont: Equatable, Sendable {
    public let base: Font
    public let textStyle: Font.TextStyle?
    public let lineHeight: CGFloat?
    public let tracking: CGFloat?
}

public struct SpectrumDuration: Equatable, Sendable {
    public let base: Duration
    public let reduced: Duration
    public func resolve(reduceMotion: Bool) -> Duration
}

public struct SpectrumElevation: Equatable, Sendable {
    public let xOffset: CGFloat
    public let yOffset: CGFloat
    public let blur: CGFloat
    public let color: SpectrumColor
    public let opacity: Double
}
```

All value types are `Sendable` (Swift 5.9+ concurrency-friendly).

## 5. Theme

```swift
public struct Theme: Equatable, Sendable {
    public enum Base { case light, dark }

    public let name: String
    public let base: Base

    public init(name: String, base: Base, overrides: ThemeOverrides = .empty)

    public static let light: Theme
    public static let dark:  Theme
}

public struct ThemeOverrides: Equatable, Sendable {
    public static let empty: ThemeOverrides

    public func setting(_ keyPath: KeyPath<ColorTokens, SpectrumColor>,
                        to color: SpectrumColor) -> ThemeOverrides
    public func setting(_ keyPath: KeyPath<SpacingTokens, CGFloat>,
                        to value: CGFloat) -> ThemeOverrides
    // … similar for the remaining 6 categories
}
```

## 6. SwiftUI Environment Integration

```swift
public extension EnvironmentValues {
    var spectrumTheme: Theme { get set }    // default: .light
}

public extension View {
    func spectrumTheme(_ theme: Theme) -> some View
    func spectrumFont(_ font: SpectrumFont) -> some View
    func spectrumAnimation(_ duration: SpectrumDuration) -> Animation
}
```

The `\.spectrumTheme` environment value is the single anchor for theme propagation.

## 7. Consumer Usage Example

```swift
import SwiftUI
import SpectrumUIFoundations

struct ProfileCard: View {
    var body: some View {
        VStack(alignment: .leading, spacing: Spectrum.spacing.s200) {
            Text("Daisy Smith")
                .spectrumFont(Spectrum.typography.headingM)
                .foregroundStyle(Spectrum.color.text.body)
            Text("Senior Engineer")
                .spectrumFont(Spectrum.typography.bodyS)
                .foregroundStyle(Spectrum.color.text.muted)
        }
        .padding(Spectrum.spacing.s400)
        .background(Spectrum.color.background.primary,
                    in: .rect(cornerRadius: Spectrum.radius.s200))
    }
}

// Brand override
@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ProfileCard()
                .spectrumTheme(.init(
                    name: "MyBrand",
                    base: .light,
                    overrides: ThemeOverrides.empty
                        .setting(\.accent.s500, to: SpectrumColor(lightHex: 0xFF1976D2,
                                                                  darkHex:  0xFF42A5F5))
                ))
        }
    }
}
```

## 8. Stability & Versioning

| Change | Bump |
|--------|------|
| Adding a new token (Spectrum publishes one) | MINOR |
| Adding a new category (Spectrum introduces one) | MINOR |
| Renaming or removing any of the eight category accessors | MAJOR |
| Removing a token previously shipped | MAJOR |
| Changing a token's `valueType` | MAJOR |
| Adding a new built-in `Theme` (e.g., `darkest`) | MINOR |
| Changing the `Theme` initializer signature | MAJOR |
| Adding a `View.spectrum…` modifier | MINOR |
| Removing or renaming a `View.spectrum…` modifier | MAJOR |

Pre-1.0.0 (`0.x.y`): MINOR may include breaking changes per the constitution; the table
above describes 1.0.0+ behavior.

## 9. What This Contract Does NOT Cover

The following are intentionally **not** part of v0.2.0's public surface:

- Per-token in-line override modifier (e.g., `.spectrumColor(\.accent.s500, .blue)`).
  Use a one-key Theme instead. Per-token sugar may arrive in v0.3.x.
- Spectrum themes beyond `light`/`dark`. (`darkest`, `wireframe` are deferred.)
- Custom font registration / brand-typeface bundling.
- A SwiftUI preview palette of every token. (Future companion target.)
- Direct access to the underlying `lightHex` / `darkHex` numeric values of a
  `SpectrumColor` — those are implementation detail; only `ShapeStyle` resolution is
  contracted.
