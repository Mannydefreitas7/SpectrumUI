# ``SpectrumUIMolecules``

The Molecules layer of SpectrumUI: composed components built from atoms.

## Overview

Molecules depends on `SpectrumUIFoundations`, `SpectrumUIIcons`, and `SpectrumUIAtoms`. It provides composed components — SearchField, Card, Toast, and similar — that combine multiple atoms into a single semantic unit while matching Adobe Spectrum's specifications.

This documentation will fill in as components are ported.
