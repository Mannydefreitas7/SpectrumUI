# ``SpectrumUIAtoms``

The Atoms layer of SpectrumUI: primitive components.

## Overview

Atoms depends on `SpectrumUIFoundations` for tokens and theming. It provides primitive interactive components — Button, Checkbox, TextField, Badge, and similar — that match Adobe Spectrum's specifications for visuals, animations, states (hover, focus, pressed, disabled), and size variants.

This documentation will fill in as components are ported.
