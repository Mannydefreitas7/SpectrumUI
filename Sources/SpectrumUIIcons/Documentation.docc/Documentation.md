# ``SpectrumUIIcons``

The Icons layer of SpectrumUI: Spectrum's icon assets and SF Symbol bridging.

## Overview

Icons depends on `SpectrumUIFoundations` for sizing and color tokens. It provides the icon set Adobe Spectrum defines, available as both raster/vector assets and (where appropriate) bridged SF Symbols. Higher layers compose icons into atoms and molecules.

This documentation will fill in as the icon set is ported.
