# ``SpectrumUIFoundations``

The Foundations layer of SpectrumUI: design tokens, theme primitives, and shared utilities consumed by every higher layer.

## Overview

Foundations is the bottom of the SpectrumUI stack. It exposes the typed token system (color, spacing, typography, motion, elevation, radius, opacity, sizing) and the SwiftUI `EnvironmentValues` that propagate theme and density throughout an application. It has zero dependencies on other SpectrumUI products.

This documentation will fill in as components and tokens land.
